# 강의동 2층 독립 검수 기록

대상: `src/data/lecture_2f.ts` (PDF 1페이지 「2층 강의동 화장실 확대평면도 (변경후)」, 여자 화장실)
검수자: 작성자와 분리된 검증 에이전트(verifier). 회차마다 새 에이전트다. 작성자의 결론과 앞선 회차의 결론을 받지 않고 도면을 직접 읽었다.
검수 자료: `work/plans_300/plan_1.jpg`, `work/measure/p1/` 의 눈금자 타일과 선분, 좌표가 풀린 모델, 평면 화면. 검수자의 확대본, 측정 스크립트, 근거 메모는 `work/verify/p1/v1/` ~ `v5/` 에 있다(git 제외).
대상은 도면 근거 품목 76개다. 상식 보완 품목(`lecture_2f_added.ts`, 39개)은 대상이 아니다.

이 탭은 강의동 계열의 대표로 먼저 썼다. 여기서 나온 지적을 강의동 3층과 4층에 넘겼다. 그래서 회차가 5번이다. 1차는 전체를 봤다. 2차부터는 앞선 회차 뒤에 값이 바뀐 품목만 봤다.

## 1차와 2차의 주요 불일치와 처리

1차와 2차는 검수자의 근거 메모가 파일로 남아 있지 않다. 아래는 작성자의 수정 보고와 측정값 문서(`docs/drawings/lecture_2f_measurements.md`)에서 확인되는 것만 적었다. 불일치의 전체 목록은 아니다.

| 대상 | 내용 | 처리 |
|---|---|---|
| 축척 | 가로와 세로의 축척이 다르다 | `mmPerPxY` 를 넣었다(가로 4.352, 세로 4.372) |
| 서측 벽의 기울기 | 2차 검수자가 식으로 냈다: 서측 벽 중심 px = 0.0038 × y + 1828.5. 원점 x 1836은 y 약 2000에서만 맞는다 | 측정값 문서에 기록했다. 보정값은 그대로다 |
| 바닥 높이 | 바닥을 +10 올려서 그렸다 | 바닥 윗면을 z 0으로 고쳤다. 규칙 「바닥 윗면 z 0」을 지침서에 넣었다 |
| 「600」 치수 | 동쪽 눈금을 조적벽의 중심(2077px)으로 읽었다. 눈금은 조적벽의 서쪽 면(2062 ~ 2064px)에 있다 | 다시 읽었다. 환산 594로 표기와 맞다. 600은 점검구의 개구 폭이다. 문짝 폭의 근거가 아니다 |
| 모델 범위 밖의 구조 | 화장실 범위 밖으로 뻗는 구조를 넣었다 | 뺐다. 규칙 「모델 범위 밖의 구조는 넣지 않는다」를 지침서에 넣었다 |
| `door-ps-hatch` | 문짝의 위치 | 그려진 문짝은 문틀 안에 있다. 문짝을 문틀 안으로 옮겼다 |

| `floor-main` remark | 「+」 구역의 경계와 구배 화살표의 서술 | 도면에 그려진 대로 다시 적었다 |

## 3차 검수

축척과 원점을 다시 구했다. 가로는 4,600의 양 끝에서 평균 4.354mm/px다. 세로는 4.362 ~ 4.372mm/px다. 벽 선은 보정값의 원점 기준으로 0.6px 안에서 맞는다.

## 4차 검수

범위 5개 항목이 모두 도면과 맞았다.

- `door-ps-hatch`: 경첩 차이 8.6mm, 폭 530 대 536, 각도 315 대 315.05, 두께 30 대 30.5.
- 점검구 개구는 막히지 않는다.
- 코너 비드 6개: 모서리와 0 ~ 3mm. 지시선 원이 모서리를 감싼다. 7, 8의 주기는 도면대로 「코너 비트 설치」다.
- 칸막이 주기: 화살표 끝 (2353, 2314)px는 `partition-2` 위에 있다.
- 「+」 구역의 경계: 모두 2mm 안이다.

## 5차 검수

검수자가 직접 구한 값:

- 상세도의 표기 450의 눈금은 y 574.5 / 780.6px다. 세로 축척은 2.183mm/px다.
- 문틀 머리의 아랫선 중심은 y 812.5px다. 아래 면은 2,450 − (812.5 − 780.6) × 2.183 = 2,380이다. 모델과 같다.
- 단면 「A」의 절단선은 고정 유리 구간을 지난다. 상세도는 문틀 머리의 높이와 유리의 상단을 정한다. 문짝의 높이는 정하지 않는다. 문짝을 `assumed`, 유리를 `scaled` 로 둔 출처 표시가 맞다.
- 점검구 서쪽 문틀: 바깥 선 394, 안쪽 면 424 → 턱 Y 2,816 → 435, 남쪽 끝 2,907. 모델과 맞다. 문짝과 겹치는 도형은 0건이다.
- `wall-mop-ps` 의 북쪽 면 2,778은 마감선이다. 다른 벽과 같은 기준이다.
- 수채기실 칸막이: 지시선은 동쪽 패널에 닿는다. note는 `partition-mop` 에만 있다.

수정 뒤의 확인(조율자, 계산만 했다):

- X 4,380 ~ 4,443, Y 2,214 ~ 3,970, Z 2,380 ~ 2,450에 걸치는 상자는 코너 비드의 날개 2개뿐이다. 개구 위를 채우는 상자는 없다.
- 코너 비드 7, 8은 z 0 ~ 2,450이다. 문틀 머리 `door-entrance-head` 는 X 4,443 ~ 4,600, Z 2,380 ~ 2,450이다.
- `note` 에 석고보드 주기를 가진 품목은 없다.
- 바닥의 띠(X 123 ~ 997, Y 1,590 ~ 1,620)는 빈 곳 0, 겹침 0이다.

6차 검수는 돌리지 않았다. 수정이 모두 5차 검수자의 판독을 그대로 적용한 것이기 때문이다.

## 표기 치수를 따라서 선 위치와 다른 곳

- 조적벽(수채기실의 동쪽): 모델 X 1,000 ~ 1,100. 도면 선은 X 987 ~ 1,086이다. 인쇄 치수 1,050(벽 중심)을 따랐다.
- 점검구 동쪽 문틀의 바깥 면: 모델 X 1,000. 도면 선은 X 988이다. 인쇄 치수 600과 1,050을 따랐다.

## 모델 제외 항목

- 「A」 단면상세도의 석고보드(문틀 머리 위, 복도 쪽), 스터드, 복도 천장재: 화장실 천장보다 위이거나 복도 쪽이다. 주기 원문 「THK.9.5 석고보드2겹 / 퍼티 위 수성광택페인트 2회 (출입구 부분)」은 `door-entrance-head` 의 remark에 있다.
- 「+」 해치의 경계선: 형상으로 나누지 않았다. 구역의 주기 원문은 `floor-main` remark에 있다.
- 화장실 범위 밖으로 뻗는 구조, 입면·단면 표시 기호, FL·CH 표기.

## 판정불가와 남은 차이

- 출입문 문짝의 상단 높이: 상세도는 고정 유리 구간을 자른다. 문짝의 높이는 도면에 없다. 문틀 머리의 아래 면(2,380)까지로 가정했다.
- 상세도의 문틀 머리 폭(약 179)과 평면의 문틀 폭(150)이 다르다. 평면 범위는 평면도를 따랐다. 높이만 상세도를 따랐다.
- 서측 창 옆 코너 비드 1, 2의 X: 스캔 기울기로 12 ~ 17mm 다르다.
- 창 옆 코너 비드 dims의 문구 「바닥에서 천장까지」: 도형은 1,200 ~ 2,100이다. 공용 부품의 고정 문구다. 통합 때 고친다.
- 칸 문의 경첩 쪽이 칸막이 끝과 약 6mm 겹친다. 출입문의 아래가 재료분리대(0 ~ 10)와 겹친다. 검수를 통과한 연구동 3층과 같은 형상이라 고치지 않았다.
- 창대, 창 상단, 하부 틈, 설치 높이 같은 `assumed` 높이: 평면에 근거가 없다.
