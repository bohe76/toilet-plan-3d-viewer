### 1차 뒤의 후속 수정

다른 탭(강의동 2F, 3F)의 검수에서 나온 결함을 4F에도 대조했다.

- **「A」 단면상세도와 출입구 높이.** 상세도의 표기 300으로 세로 축척(2.190mm/px)을 구했다. 문틀 머리의 윗면은 화장실 천장(2,800)과 같은 높이다. 아래 면은 2,730이다. 출입문, 고정 유리, 문틀의 상단을 2,100(가정)에서 2,730(환산)으로 고쳤다.
- **벽 마감 면이 PS 점검구 개구를 막고 있었다.** 개구 둘레로 나눴다(옆, 아래, 위).
- **점검구 문틀.** 문설주의 북쪽 끝과 수채기실·PS 사이 벽의 북쪽 면을 구조선(Y 2,798)에서 마감선(Y 2,776)으로 옮겼다. 문짝 두께를 20(가정)에서 30(환산)으로 고쳤다.
- **창 옆 코너 비드(1, 2, 5, 6).** 높이를 창대 ~ 창 상단(1,200 ~ 2,100, 가정)으로 고쳤다.
- **칸막이 주기의 note.** 지시선이 닿는 품목(`partition-2`, 수채기실의 동쪽 패널)에만 두었다. 수채기실 칸막이를 `partition-mop`(동쪽)과 `partition-mop-west` 로 나눴다. 다른 칸막이의 높이와 두께는 `assumed` 다.

## 2차 검수 (2026-11-22)

범위: 1차 뒤에 값이 바뀐 품목(출입구의 높이, PS 점검구, 창 옆 코너 비드, 칸막이 주기).

종합 판정: **조건부 PASS**. 높음 0건, 중간 1건, 낮음 2건.

검수자가 직접 구한 값:

- 상세도의 표기 300은 y 575.5 → 712.5px(137px)다. 세로 축척은 2.190mm/px다. 스터드 C-120이 55px라서 가로 축척도 같다.
- 문틀 머리의 아랫선은 y 743 ~ 746px(중심 744.8)다. 아래 면은 2,800 − (744.8 − 712.5) × 2.190 = 2,729다. 모델의 2,730과 맞다.
- 단면 「A」는 고정 유리 구간을 자른다. 상세도는 문틀 머리의 높이와 유리의 상단을 정한다. 문짝의 높이는 정하지 않는다.
- 점검구: 문짝 폭 536, 각도 315.3, 두께 31. 문설주의 북쪽 끝과 `wall-mop-ps` 의 북쪽 면은 마감선이다. 문짝과 겹치는 도형은 0건이다. 개구 안의 도형도 0건이다.
- 창 옆 코너 비드 4개: 모서리가 모두 지시선 원 안에 있다.
- 칸막이 주기: 지시선은 수채기실의 동쪽 패널과 `partition-2` 에 닿는다. note는 이 두 품목에만 있다.

| 3 | 낮음 | `door-ps-hatch` 의 경첩 | 도면 X 438, 데이터 X 449. 모델의 문설주에 홈이 없어서 작성자가 경첩을 옮긴 것이다 | 문설주를 홈 모양대로 상자 4개로 나눴다. 경첩을 (438, 2,788)로 되돌렸다 |

수정 뒤의 확인(조율자, 계산만 했다):

- `wall-entrance-head` 는 없다. X 4,380 ~ 4,442, Y 2,217 ~ 3,970, Z 2,730 ~ 2,800에 걸치는 상자는 문설주 면 2개(두께 3)와 코너 비드 2개뿐이다. 개구 안을 채우는 상자는 없다.
- 코너 비드 7, 8은 z 0 ~ 2,800이다.
- `door-ps-hatch` 의 경첩은 (438, 2,788), 폭은 537이다. 문설주는 서쪽 399 ~ 425 / 399 ~ 438, 동쪽 966 ~ 1,000 / 951 ~ 1,000이다. 2차 검수자의 판독(서쪽 홈 X 425, 동쪽 홈 X 966, 경첩 X 438)과 같다.
- 2차 검수자의 겹침 계산 스크립트(`v2_overlap.py`)를 수정 뒤의 모델에 돌렸다. 문짝과 겹치는 도형은 0건이다. 개구 안의 도형도 0건이다. 같은 품목 안의 문설주와 문짝 사이는 작성자의 계산으로 2.4 떨어져 있다.
- `note` 에 석고보드 주기를 가진 품목은 없다.

3차 검수는 돌리지 않았다. 수정이 모두 2차 검수자의 판독을 그대로 적용한 것이기 때문이다.

## 표기 치수를 따라서 선 위치와 다른 곳

- 수채기실의 동쪽 면(조적벽의 서쪽 면): 모델 X 1,000. 도면의 구조선은 X 992 ~ 995, 마감선은 X 975다. 조적벽은 인쇄 치수(벽 중심 1,050, W=100)를 따랐다.
- 점검구 동쪽 문틀의 바깥 면: 모델 X 1,000. 도면 선은 X 995다. 인쇄 치수 600을 따랐다.

## 모델 제외 항목

- 「A」 단면상세도의 석고보드(문틀 머리 위, 복도 쪽), 스터드, 앵커볼트, 철판, 복도 천장재: 화장실 천장보다 위이거나 복도 쪽이다. 주기 원문 「THK.9.5 석고보드2겹 / 퍼티 위 수성광택페인트 2회 (출입구 부분)」은 `door-entrance` 의 remark에 있다.
- 「+」 해치의 경계선: 형상으로 나누지 않았다. 구역의 주기 원문은 `floor-main` remark에 있다.
- 입면·단면 표시 기호, FL·CH 표기: 실물 품목이 아니다.

## 판정불가로 남은 것

- 출입문 문짝의 상단 높이: 상세도는 고정 유리 구간을 자른다. 문짝의 높이는 도면에 없다. 문틀 머리의 아래 면(2,730)까지로 가정했다. dims에 `assumed` 로 적었다.
- 서측 벽 마감선의 기울기: 도면의 선은 북쪽 X 109에서 남쪽 X 122로 기운다(스캔 사다리꼴). 모델은 X 120 하나로 두었다. 서측 창 옆 코너 비드 1, 2의 X가 그만큼(약 10mm) 다르다.
- 창대, 창 상단, 하부 틈, 설치 높이 같은 `assumed` 높이: 평면에 근거가 없다.
