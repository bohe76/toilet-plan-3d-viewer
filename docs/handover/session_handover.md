## 3. 확정된 결정

- 3D 방식은 C안이다(치수 기반 모델 + 스캔 도면 깔기).
- 조명 검토는 주목적이 아니다. 손글씨 위치 마커만 넣는다.
- 탭을 만들 때마다 독립 검증 에이전트가 실제 도면과 대조한다.
- 도면의 선 위치와 표기 치수가 다르면 표기 치수를 따른다. (작성자 판단. 건축 도면의 일반 원칙이다. 보헤님이 바꾸라고 하면 바꾼다.)
- 아이소·평면 뷰의 기본 절단 높이는 1,200이다. 눈높이 뷰는 절단하지 않는다.
- TypeScript는 6.x를 쓴다. `typescript-eslint` 가 7.0을 지원하지 않는다.

## 4. 미결 질문 (보헤님 확인 필요)

1. **세면대 상판**: 도면으로는 상판 유무가 판정되지 않는다. 지금 모델은 세면기 2개만 있다. 상판이 있으면 깊이와 높이를 알려 달라.
2. **세면대 하부 칸막이 (500x800)**: 점선 1개만 판독된다. 실제로 몇 장이고 어디에 있는지 확인이 필요하다.
3. **하부 서측 실 (X 표시)**: 용도를 알 수 없다. PS인지 창고인지 알려 달라.
4. **가정한 높이**: 창대 1,200, 문 2,100, 세면기 800, 선반 850 등은 가정값이다. 실제 값이 있으면 알려 달라. 목록은 [research_3f_measurements.md](../drawings/research_3f_measurements.md) 7절에 있다.

## 5. 환경 메모

### OMC 훅 시간 초과

- 증상: 도구 호출이 「PreToolUse hook error: [node]: the hook did not finish」로 거부된다.
- 원인: OMC 5.7.5 플러그인의 `PreToolUse` 훅(`pre-tool-enforcer.mjs`)이 모든 도구 호출 앞에서 node를 2번 띄운다. CPU 부하가 100%일 때 실행에 2.5 ~ 4.1초가 걸렸다. 제한이 5초였다.
- 조치(2026-11-21): `~/.claude/plugins/cache/omc/oh-my-claudecode/5.7.5/hooks/hooks.json` 의 `PreToolUse` 2개(`*`, `Bash`)의 `timeout` 을 5에서 20으로 바꿨다. 세션을 다시 시작한 뒤 적용됐다. 적용 후 거부는 드물게만 발생했다.
- 주의: 플러그인 캐시 파일을 직접 고친 것이다. OMC를 업데이트하면 5로 돌아간다. `omc-patch-all` 에 등록해야 유지된다.
- 거부되면 같은 호출을 다시 보낸다.

### 그 밖

- 이 PC는 다른 Claude 세션, Codex, `next dev`, Docker가 함께 돌 때 CPU 부하가 100%가 된다. 설치와 캡처가 느려진다.
- 2026-11-21 세션에서 브라우저 MCP(chrome-devtools, playwright)가 연결에 실패했다. 화면 확인은 Chrome 헤드리스 캡처로 했다. 명령은 [measurement_workflow.md](../guides/measurement_workflow.md) 6절에 있다.
- 측정 스크립트용 파이썬 환경은 프로젝트에 없다. 이전 세션은 임시 폴더의 venv를 썼다. README의 명령으로 `.venv` 를 만든다.
- `work/` 는 git에 넣지 않는다. 지우면 `prep_plans.py` 와 `measure_plan.py` 로 다시 만든다.
