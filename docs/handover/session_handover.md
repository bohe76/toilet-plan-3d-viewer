# 현재 상태와 다음 작업

기준일: 2026-11-21

## 1. 현재 상태

| 항목 | 상태 |
|---|---|
| 도면 8장 기울기 보정 이미지 | 완료 (`public/plans/`, `work/plans_300/`) |
| 뷰어 (탭 8개, 3D, 레이어, 절단 높이, 정보 패널, 원본 도면 보기) | 구현 완료 |
| 연구동 3층 모델 (파일럿, 도면 모드) | 작성 완료, 독립 검수 3회, 최종 PASS |
| 실사 모드 | 미착수. 요구는 확정됐다 ([viewer_spec.md](../spec/viewer_spec.md) 9절) |
| 나머지 7개 탭 모델 | 미작성. **보헤님 지시가 있을 때까지 착수하지 않는다** |
| typecheck, lint, build | 통과 |

보헤님이 실제 브라우저에서 마우스 오른쪽 드래그 이동을 확인했다. 그 밖의 조작(회전, 확대, 호버 툴팁, 클릭, 더블클릭, 단축키)은 확인 결과를 받지 못했다.

## 2. 다음 작업 순서 (연구동 3층 탭만)

1. 좌상단 마감 표를 300dpi로 읽는다. 재질에 반영한다.
2. 상식 보완 품목을 모델에 추가한다. 출처는 「가정」이다. 목록은 [viewer_spec.md](../spec/viewer_spec.md) 9.2절 7번에 있다.
   - 세면대 상판을 넣는다. 남서 실은 바닥 구배가 중앙으로 모이는 습식 실로 만들고 중앙에 배수구를 넣는다.
3. 실사 모드를 구현한다. 재질(PBR), 천장, 광원, 그림자, AO, 환경 반사, 톤 매핑, 곡면 위생기구. 색상은 호텔 화장실 느낌이다.
4. 고품질 렌더 버튼(경로 추적)을 구현한다. 라이브러리는 공식 문서로 먼저 확인한다.
5. 화살표 키 이동과 화면 이동 버튼을 추가한다.
6. 화면을 캡처해서 확인한다. 독립 검증 에이전트로 도면 근거 품목을 다시 검수한다. 추가 품목 목록을 따로 보고한다.
7. 보헤님 확인을 받는다. 그 뒤에 나머지 7개 탭의 착수 여부를 묻는다.

## 3. 확정된 결정

- 3D 방식은 C안이다(치수 기반 모델 + 스캔 도면 깔기).
- 품질 목표는 실사다. 색상은 호텔 화장실 느낌이다.
- 도면에 없어도 상식적으로 있어야 하는 것은 넣는다. 높이는 상식값으로 정한다. 다시 묻지 않는다.
- X 표시는 물이 빠지는 방향(바닥 구배)이다.
- 위생기구 형상은 직접 만든다. 외부 3D 모델을 받지 않는다.
- 탭을 만들 때마다 독립 검증 에이전트가 실제 도면과 대조한다.
- 도면의 선 위치와 표기 치수가 다르면 표기 치수를 따른다. (작성자 판단)
- 아이소·평면 뷰의 기본 절단 높이는 1,200이다. 눈높이 뷰는 절단하지 않는다.
- TypeScript는 6.x를 쓴다. `typescript-eslint` 가 7.0을 지원하지 않는다.

## 4. 해결된 질문

| 질문 | 답 (2026-11-21 보헤님) |
|---|---|
| 세면대 상판이 있는가 | 상식적으로 있어야 하는 것은 넣는다. 상판을 넣는다 |
| 세면대 하부 칸막이의 수와 위치 | 상식적으로 정한다 |
| X 표시 실의 용도 | X는 물이 빠지는 방향이다. 중앙에 배수구를 넣는다 |
| 가정한 높이의 실제 값 | 없다. 상식적인 높이로 정한다 |

## 5. 환경 메모

### OMC 훅 시간 초과

- 증상: 도구 호출이 「PreToolUse hook error: [node]: the hook did not finish」로 거부된다.
- 원인: OMC 5.7.5 플러그인의 `PreToolUse` 훅(`pre-tool-enforcer.mjs`)이 모든 도구 호출 앞에서 node를 2번 띄운다. CPU 부하가 100%일 때 실행에 2.5 ~ 4.1초가 걸렸다. 제한이 5초였다.
- 조치(2026-11-21): `~/.claude/plugins/cache/omc/oh-my-claudecode/5.7.5/hooks/hooks.json` 의 `PreToolUse` 2개(`*`, `Bash`)의 `timeout` 을 5에서 20으로 바꿨다. 세션을 다시 시작한 뒤 적용됐다. 적용 후 거부는 드물게만 발생했다.
- 주의: 플러그인 캐시 파일을 직접 고친 것이다. OMC를 업데이트하면 5로 돌아간다. `omc-patch-all` 등록은 보헤님이 처리한다.
- 거부되면 같은 호출을 다시 보낸다.

### 그 밖

- 이 PC는 다른 Claude 세션, Codex, `next dev`, Docker가 함께 돌 때 CPU 부하가 100%가 된다. 설치와 캡처가 느려진다.
- 2026-11-21 세션에서 브라우저 MCP(chrome-devtools, playwright)가 연결에 실패했다. 화면 확인은 Chrome 헤드리스 캡처로 했다. 명령은 [measurement_workflow.md](../guides/measurement_workflow.md) 6절에 있다.
- 측정 스크립트용 파이썬 환경은 프로젝트에 없다. README의 명령으로 `.venv` 를 만든다.
- `work/` 는 git에 넣지 않는다. 지우면 `prep_plans.py` 와 `measure_plan.py` 로 다시 만든다.
- 개발 서버는 세션 종료 때 내렸다. `pnpm dev` 로 다시 띄운다.
